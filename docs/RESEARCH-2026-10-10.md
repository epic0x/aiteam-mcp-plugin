# Marketplace research: Claude connector directory + ChatGPT plugin directory

Fetched 2026-10-10 from the live docs (not memory). Sources:
- Anthropic: claude.com/docs/connectors/building/submission, /review-criteria, /authentication; support.claude.com Software Directory Policy (13145358)

## 1. Anthropic: Claude Connectors Directory
| Item | Requirement (verbatim-level) |
|---|---|
| Where | claude.ai/directory/manage -> Submit new -> MCP connector. Any paid Claude plan can submit |
| Server | Remote, HTTPS, Streamable HTTP. Local servers only inside a plugin (MCPB desktop extensions no longer accepted) |
| Auth | OAuth 2.0: DCR (default), CIMD (default), Anthropic-held client creds, or custom connection. PKCE S256 required. 401 + `WWW-Authenticate: Bearer resource_metadata=...`. PRM `resource` must equal the URL exactly; only the first `authorization_servers` entry is used |
| Redirects | `https://claude.ai/api/mcp/auth_callback` + Claude Code loopback on any port (localhost and 127.0.0.1) |
| Token endpoint | form-urlencoded, `invalid_grant` on dead refresh, rotate refresh tokens, < 10 s (refresh < 30 s). Egress 160.79.104.0/21 |
| Per-user URLs | Supported: "URL pattern" (anchored regex, e.g. `^https://[a-z0-9-]+\.mcp\.example\.com/mcp$`) with DCR or CIMD. Slower review |
| Tools | Every tool: `title` + `readOnlyHint` or `destructiveHint`; name <= 64 chars; read and write split; narrow descriptions; no prompt-injection patterns; useful errors; frugal tokens |
| Banned | Moving money/crypto or executing financial transactions; AI image/video/audio generation; ads. Must not read Claude memory/chat history; collect only needed conversation data |
| Listing | Name <=100, one-liner <=200, description <=2000, 1-5 categories, docs URL, privacy policy URL, support contact, icon, permanent slug, >=3 example prompts |
| Review | Test account with populated data. Automatic policy scan, then listed as **Community** by default; popular ones escalated to **Verified** (human functional test). Escalation: mcp-review@anthropic.com | <!-- id-scan: allow (public Anthropic review address) -->
| Money | No fee/rev-share rule found; just no ads |

## 2. OpenAI: ChatGPT (and Codex) plugin directory
| Item | Requirement |
|---|---|
| Where | platform Plugins page: upload plugin ZIP (plugin.json + mcp.json, optional skills). Org owner or Apps Management Write |
| Identity | Individual or business verification required; listing shows that name |
| Server | One remote MCP server per plugin. Domain verification: plain-text token at `https://<host>/.well-known/openai-apps-challenge`. Changing the server URL later = contact support |
| Auth | OAuth 2.1 per MCP auth spec: PRM, AS metadata with `code_challenge_methods_supported: [S256]`, echo `resource`, CIMD / DCR / predefined client. No API-key or bearer-token connect flow in the portal |
| Redirects | `https://chatgpt.com/connector_platform_oauth_redirect` (stable, if AS returns `iss` on every authorization response + advertises `authorization_response_iss_parameter_supported`), else `https://chatgpt.com/connector/oauth/{callback_id}`. CIMD client_id `https://chatgpt.com/oauth/client.json` |
| Tools | Explicit booleans for `readOnlyHint`, `destructiveHint`, `openWorldHint` on every tool; verb names; no "official/best"; each operation its own tool (no generic executor); minimal inputs, never full chat history; no trace/session IDs in responses |
| Banned | Unofficial connectors / pass-through layers to third-party services; collecting secrets (API keys, OTPs, passwords); money/crypto transfers or trades; restricted data |
| Money | **No selling digital goods inside the plugin.** Users may sign in to an existing paid account; may say a feature needs another plan and link to an info page; no checkout links, no upsell, no plugin-only surcharge. Name/description must not mention pricing or trials |
| Name | No "MCP", "MCP Server" or "Plugin" appended; must not imply OpenAI made it |
| Review | Reviewer test account (no MFA, no email codes), **5 positive + 3 negative test cases**, a **video walkthrough URL**, release notes, policy attestations. Human review, email feedback, appeal by reply. After approval YOU press Publish; server tool changes re-scanned daily |

## 3. Gap list: what the reference gateway lacks today
Live check 2026-10-10: `<son>.aiteam.space/mcp` no-auth 401 OK, PRM + AS metadata OK, DCR + PKCE S256 + refresh rotation OK.

| # | Gap | Claude | ChatGPT |
|---|---|---|---|
| G1 | **Login = a shared approval code typed by the owner.** Reviewers and real users need a per-user account login (aiteam.space sign-in) | blocker | blocker |
| G2 | **One box, one hostname.** A store listing is one product URL. ChatGPT allows one server URL per plugin; Claude allows a URL pattern but reviews it slower | partial | blocker |
| G3 | **0 of 10 tools have `title` or annotations** (`hermes mcp serve` 1.29.1 emits none) | blocker | blocker |
| G4 | Tool set is a messaging bridge (read/send Telegram/Discord/WhatsApp messages, `permissions_respond` approves exec). Reads as a pass-through to third-party platforms + remote command approval | high risk | likely reject |
| G5 | Redirect allowlist = claude.ai only; no `chatgpt.com` callbacks | ok | blocker |
| G6 | No CIMD (`client_id_metadata_document_supported`), no `iss` in authorization response | ok (DCR) | needed for stable redirect |
| G7 | No `offline_access`/`openWorldHint`, docs carry multi-line Python docstrings | minor | minor |
| G8 | No privacy policy / docs page / support contact / icon / test account / 8 test cases / video for this product | blocker | blocker |
| G9 | Publisher identity not chosen (who verifies with OpenAI, who submits on Anthropic) | blocker | blocker |
| G10 | Trading add-on and image/video tools must never be exposed through the connector | policy | policy |

## 4. Proposed architecture (needs owner decision D1)
One hosted relay, `https://mcp.aiteam.space/mcp`, is the only URL either store sees.
- OAuth = sign in with the aiteam.space account (fixes G1, G8 test account).
- Each Son (hosted on aiteam.space or installed on the user's own computer) dials OUT to the relay over a tunnel; the relay routes the call to that user's Son. No inbound ports, no per-user hostname (fixes G2).
- The relay exposes a small, reviewed tool set with annotations (fixes G3, G4): e.g. `ask_son` (write), `get_son_status` (read), `list_son_tasks` (read). Messaging-bridge and exec-approval tools stay off by default.
- Installer = one command that installs Hermes (if missing) + the relay connector and pairs it to the aiteam.space account.

Alternative: keep per-box hostnames (`<slug>.mcp.aiteam.space`) with a Claude URL pattern. Faster for Claude, impossible for ChatGPT.

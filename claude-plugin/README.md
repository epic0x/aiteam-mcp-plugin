# aiteam.space plugin for Claude

One install: the aiteam MCP connector (`https://mcp.aiteam.space/mcp`, OAuth through aiteam.space) plus the
`aiteam-mcp` skill (who we are, hand-off, one thread per task, standing rule 0 for status questions).

- `.claude-plugin/plugin.json`: plugin manifest.
- `.mcp.json`: the remote MCP server.
- `skills/aiteam-mcp/SKILL.md`: generated by `scripts/build_skill.py` from `connector/aiteam_connector/usage_guide.py`.
  Edit the guide, never this copy (tests fail when it is stale).

Validate before submitting: `claude plugin validate ./claude-plugin`.
